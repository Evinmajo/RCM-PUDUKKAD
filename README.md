# Pudukad Cart And Courier

Build the complete frontend e-commerce storefront for HANNAN SUPERMARKET-RCM PUDUKKAD according to the attached specification. Write all application pages, components, and logic in plain JavaScript (.jsx and .js) without TypeScript types or interfaces. Include:
- Homepage with product banners, categories, and featured products
- Product search, category filters, sorting, and pagination
- Product detail pages with images, descriptions, prices, and stock availability
- Shopping cart with quantity adjustments, item removal, and subtotal calculation
- Customer authentication (login, registration) and guest checkout
- Checkout flow with delivery address, shipping calculation, Cash on Delivery (COD), and Razorpay checkout options
- Order confirmation, order details, and delivery tracking screens
- Brand identity for HANNAN SUPERMARKET-RCM PUDUKKAD
